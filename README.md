# CapitalPro · Actualizaciones

Este repositorio publica el manifiesto de versión que el sistema de escritorio
de CapitalPro consulta para saber si hay una versión nueva disponible.

## Contenido

- `version.json` — versión publicada, enlace de descarga y notas del cambio.

No contiene código fuente ni datos de clientes.

## Cómo se publica una versión nueva

1. Se compila el instalador y se sube a la página oficial de descargas.
2. Se actualiza `version.json` con el número nuevo y el enlace al instalador.

El número y el enlace se mueven juntos: `version.json` nunca debe anunciar una
versión cuyo instalador no esté publicado todavía.
